Proyecto: Sistema CRM para administrar reservaciones de un Hotel.
Integrantes: Daniel Hernández Hollowell y Rodríguez Romero Estefanie Guadalupe.
Descr: El proyecto consiste en el desarrollo de un Sistema CRM Hotelero que permite administrar habitaciones, huéspedes y reservaciones mediante una interfaz gráfica creada con Python y Tkinter. El sistema facilita el registro de clientes, la gestión de reservas, el control de disponibilidad de habitaciones y los procesos de Check-In y Check-Out.
